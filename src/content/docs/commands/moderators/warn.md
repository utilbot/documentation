## Command
```txt
/mod warn <user>
```

## Description
Warns a Member. Requires the warn feature to be enabled via [`/warns enable`](/commands/admins/warns).

## Permission
`MODERATE_MEMBERS`

## Arguments
| Name | Type | Description | Sample Data |
| ---- | ---- | ----------- | ----------- |
| user | USER | A user (ID should also work) | @HerrTxbias |
